## 游戏介绍

Sweet Stack 把简单的“点击放下”变成一场关于时机和稳定性的小游戏。每次落地都会改变蛋糕塔的形态和节奏；玩家需要根据移动中的目标、落点评价和塔体反馈，逐步搭出更高的蛋糕塔，同时追逐 PERFECT 连击和完整甜点图鉴。

### 游戏特色

- **精准叠放**：在移动目标对齐时放下悬挂中的蛋糕。
- **清晰反馈**：通过 PERFECT、GREAT、SAFE 了解每次落地表现。
- **弹性塔体**：准确或冒险的落点会直观地影响塔体平衡。
- **SUGAR RUSH**：连续 PERFECT 后进入短时间高分节奏。
- **甜点图鉴**：发现、熟练并完成不同甜点的挑战。
- **移动端优先**：支持触摸操作、自适应 Canvas 布局和无音频环境运行。

## 游戏循环

1. 点击或触摸，放下悬挂中的蛋糕。
2. 尽量靠近目标位置落地。
3. 根据评价、塔体晃动和下一个目标调整时机。
4. 持续叠放、解锁甜点，并挑战自己的最高记录。

## 本地体验

```bash
npm install
npm start
```

然后打开 <http://localhost:8082>。启动命令会先构建游戏，再启动本地服务器。

## 构建和发布

```bash
npm run verify:core
npm run release:web
npm run verify:release
npm run release:offline
```

| 输出目录/文件 | 用途 |
| --- | --- |
| `web-release/` | 通过部署流程发布的静态网页版本 |
| `offline-release/sweet-stack-offline.html` | 内嵌资源的离线单文件版本 |

生成产物已加入 Git 忽略规则，源码仓库只保留源码和运行时资源。

## 项目结构

| 路径 | 作用 |
